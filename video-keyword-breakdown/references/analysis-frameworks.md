# 三维度文案分析框架详解

来源：本流程内置的三维度分析体系，用于阶段 3「口播文案拆解」。
这套框架产出的叙事结构、Viral-5D 诊断、修辞手法，同时也是阶段 4 关键词标注时
判断 HOOK / EMOTION_PEAK / CTA / SOCIAL_CURRENCY / RHETORIC 标签的语义依据——
不要只依赖 keyword_candidates.py 的规则命中，规则只是召回，语义判断要回到这套框架。

## 一、TextContent Analysis 框架

### 1.1 叙事结构分析

按时间线拆解视频内容：

| 结构层 | 说明 | 典型时长占比 |
|--------|------|----------|
| 开场钩子 | 吸引注意力的开头 | 前 0-8% |
| 核心卖点 | 主要内容展开 | 8%-70% |
| 场景延伸 | 应用场景描述 | 70%-90% |
| 行动号召 | CTA 引导 | 后 10% |

这个时间区位划分正是 `keyword_candidates.py` 里 `--hook-zone-pct` / `--cta-zone-pct`
两个参数的默认值来源（0.08 / 0.10）。

### 1.2 叙事声音分析

- **人称视角**：第一/第二/第三人称
- **语气特征**：正式/口语/专业/亲切
- **节奏特点**：句子平均时长、语速变化

### 1.3 修辞手法识别（对应 RHETORIC 标签）

| 手法 | 说明 | 效果 |
|------|------|------|
| 类比 | 将抽象概念具象化 | 降低理解门槛 |
| 数据论证 | 使用具体数字 | 增强可信度（也会被打上 NUMBER_STAT） |
| 对偶 | 对仗工整的句式 | 朗朗上口 |
| 呼应 | 首尾呼应 | 结构闭环 |
| 排比 | 并列结构 | 增强气势 |

### 1.4 词库提取

分类提取关键词：核心词（产品/服务核心特征）、场景词（使用场景描述）、
卖点词（差异化卖点）、行动词（引导用户行动）。这些词库是阶段 4 里
BRAND_KEYWORD / NUMBER_STAT 候选的重要补充来源。

## 二、Viral-Abstract-Script 框架

### 2.1 Viral-5D 诊断

| 维度 | 说明 | 评分标准 | 对应关键词标签 |
|------|------|----------|----------------|
| **Hook** | 黄金开场 | 是否立即抓住注意力 | HOOK |
| **Emotion** | 情感触发 | 是否引发共鸣/笑点/惊讶 | EMOTION_PEAK |
| **爆点结构** | 节奏设计 | 是否有高潮点 | EMOTION_PEAK / TRANSITION |
| **CTA** | 行动引导 | 是否有明确下一步 | CTA |
| **社交货币** | 传播价值 | 是否值得分享/讨论 | SOCIAL_CURRENCY |

### 2.2 风格定位

| 风格 | 特点 | 适合场景 |
|------|------|----------|
| 抽象鬼畜 | 意义消解、荒诞 | 谐音梗、整活 |
| 反转剧情 | 悬念→意外结局 | 故事类 |
| 共鸣治愈 | 真实感、普通人视角 | 生活记录 |
| 科技种草 | 理性、信息密度高 | 产品测评 |

### 2.3 Hook 类型参考

1. **痛点切入**："你是不是也遇到过..."
2. **反常识**："90%的人都不知道..."
3. **数字开头**："3个方法让你..."
4. **悬念设置**："结局没想到..."
5. **情绪共鸣**："太真实了..."

这些正是 `keyword_candidates.py` 中 `HOOK_PHRASE_RE` 规则覆盖的典型句式。

## 三、Brainstorming 框架

### 3.1 核心价值拆解

```
根本需求 → 表层痛点 → 深层需求
    ↓           ↓           ↓
  为什么      遇到什么      真正想要
```

### 3.2 多方向探索

每次提出 2-3 种不同方向：

| 方向 | 核心概念 | 差异化 |
|------|----------|--------|
| A | 技术极客向 | 强调技术/材料 |
| B | 生活方式向 | 场景化叙事 |
| C | 情感共鸣向 | 亲情/友情牌 |

### 3.3 增量验证点

每个关键决策点都需验证：
- [ ] 开场钩子有效？
- [ ] 核心卖点差异化？
- [ ] 场景覆盖目标用户？
- [ ] 行动引导明确？

## 四、综合评分体系

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 结构完整性 | 20% | 是否有完整叙事结构 |
| 开场吸引力 | 20% | 3 秒是否抓住注意力 |
| 信息密度 | 15% | 信息量与时长比 |
| 情感共鸣 | 15% | 是否引发情感反应 |
| 传播潜力 | 15% | 是否值得分享 |
| CTA 有效性 | 15% | 是否有明确行动引导 |
